# Problem Statement

To create a simple Python-based Odd-Even Cricket Game where a player can play cricket against the computer.

## Scope

The project includes:

* Toss
* Batting and bowling
* Score calculation
* Wicket system
* 12-ball innings
* Target score
* Input validation

## Target Users

This project is mainly for students and beginners who want to learn Python through a simple game.

## High-Level Features

* Odd-Even toss
* Random computer numbers
* Batting and bowling system
* Score and wicket calculation
* Game result
* Play again option
